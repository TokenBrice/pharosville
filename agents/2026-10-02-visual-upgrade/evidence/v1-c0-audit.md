## Missed risks

1. **Knockout seam interaction**: the pass reads `isKnockedOut("reflection")` once at creation (`garden-hero-reflection-pass.ts:111`) and returns before any snapshot work. New cache tests must run with visual-debug knockout off, or they silently exercise the no-op path. One-line guard in the test plan would close it.
2. **Exact-matrix equality and mid-flight camera glides**: the design mandates exact `Matrix4.equals` comparisons (right call vs. tolerances), and reduced motion pins `timeSeconds = 0` + unbreathed pose, so steady-state repaints are bit-stable. But a postcard/selection glide still easing when one-shot paints land will legitimately change the camera each paint → recapture per paint until the glide settles. That is correct behavior, but the new "reuses identical static capture" test must not run during a glide, and implementers should not "fix" the recaptures by fuzzing the comparison.
3. **First-frame ordering on world replacement**: the reflection call is guarded by `if (scene.content)` (`world-renderer.ts:1145`); during the swap window no reflection render occurs, and the new content's first paint both builds and captures. The snapshot record must be reset (or derived from the new content) on content replacement, not just diffed — `scene.content.lampStatusMix` etc. read from a *new* object while the previous record holds the old object's values; a plain scalar diff handles this, but an implementer keying the record by field-identity rather than value would miss it.
4. **`--light-cycle` reduced settle is per-phase**: the light-cycle acceptance arm re-settles after each of the four hour fills (652-655), i.e. four one-shot repaints — the acceptance narrative should expect four captures (one per phase), not one, when judging reflection freshness.
5. Owner note: step 3's snapshot lives in `world-renderer.ts` beside `heroReflectionPass` (545); any future reflected-content driver outside the island part (e.g. if keeper/heron geometry ever gets layer 7 — currently untagged, verified) must join that record. The report flags this generically; the concrete untagged-geometry fact is worth pinning.
