## Implementation design

Smallest correct scope: a supported opt-in flowing **fixture observer**; honest classified duration diagnostics; preserve all existing art still semantics and urgent policy; repair late companion catch-up. Treat market event-quality qualification as the existing S1 owner's shared prerequisite, not a new director abstraction. No source edits have been made by this verification slice.

Add third argument `{ dateMode: 'fixed' | 'flowing' }`, default fixed. Choose exactly one `addInitScript` installer with epoch `fixtureGeneratedAt+60_000`; never install fixed first and overwrite afterward. The flowing fixture starts at the same observer/source-age premise as the still, then ages naturally. Leave seven route payloads/metadata immutable; this mode deliberately represents a retained snapshot. No rewritten _meta-on-every-response, no invented producer observations.

2. **`scripts/pharosville/preview.mjs` — argument validation, init block, clock reporting/config.** Introduce explicit `--fixture-clock fixed|flowing`, allowed only with `--fixture`; fixed default preserves current behavior including `--fixture --clock` calendar-only stills. 3. **`src/lib/pharosville-debug.ts` — `DebugDirectorAdmission`, `recordDebugDirectorAdmission`, `recordDebugRitual`; `src/systems/garden-director.ts` — successful-admission instrumentation; `src/pharosville-world.tsx` — forced crossing debug row.** Classify rows explicitly as `admission`, `ritual-start`, or `forced-motion`; carry `foreground` and `clockDomain: 'epoch' | 'motion'`.
