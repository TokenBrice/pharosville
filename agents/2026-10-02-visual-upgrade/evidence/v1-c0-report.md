1. **`src/three/garden-hero-reflection-pass.ts`, `createGardenHeroReflectionPass.render`: replace owner/boolean-only static gate with a bounded capture snapshot.** Preallocate two main-camera `Matrix4` snapshots, keep last effective DPR, desired target width/height, owner, reduced-mode value and last successful scene revision. A cached hit requires same owner, view/world matrix, projection matrix, dimensions, DPR, mode and scene revision and a successfully rendered current texture. Normal-motion behavior remains render-every-invocation. Compare/copy matrices without arrays, serialization, hashes or subtree scans.
2. **Same owner, add pass-local `invalidate()` revision signal.** Increment a numeric `sceneRevision` (no timer, no frame request inside the pass). Capture/commit its value and all input snapshots **only after successful renderer.render**. Owner change invalidates automatically. Cull sets strength 0 and leaves revision unconsumed; reentry restores strength and captures if view/revision differs. Exceptions leave capture dirty and preserve existing try/finally state restoration. Removing the early return without a replacement cache is not acceptable.
3. **`src/three/world-renderer.ts`, reflection call at 1145: supply scene revisions after current scene update, not before.** Store a reusable previous-static-appearance record near `heroReflectionPass`. On differences, call `invalidate()` once for that render.
