2. **Changing local ramp constants is not local.** Both headland and Danger slab colours consume `CRAG_ROCK_LOW/HIGH` (`island.ts:467-468,2344`). A2 can leave them unchanged; if a later colour-plane packet is authorized, put headland-specific derivation inside `cragColor`, not the shared constants.

Build fresh roots before every comparison.
5. **Existing tests are narrower than the packet's words.** The current month test samples the first pine pad and aggregate colour (`garden-month-record.test.ts:13-46`), not every pad or negative/zero-rank preservation. Its “leaves a neutral garden” test rebuilds the same path twice (`66-68`); replace it with absent/unavailable history against an unmodified root if that owner is touched, rather than re-pinning a duplicate-path result. Island wet-versus-crown test traverses all qualifying meshes (`island.test.ts:322-354`); it does not prove fragment-foot appearance.
6. **The first near-boat choice should not edit a global family generator.** Ordinary/procedural and GLB finish paths differ; editing cached hull/sail geometry to flatter one selected hero can alter whole-fleet identity/clearance (`ships.ts:866-897,2023-2067,2174-2247`). 7. **Effective water frequency is more than stored wavelength.** Regional `chop` multiplies the coordinate and weather raises it further (`water.ts:509-540`); the spectrum test only floors the unscaled wavelength (`water.test.ts:919-925`). `[INFERENCE]` Any spectrum revision needs a grid/pixel-footprint calculation using effective wavelength `λ / regionChop`, not merely a larger subdivision count or a raw ≥30 assertion. No aliasing defect is visually established here.
